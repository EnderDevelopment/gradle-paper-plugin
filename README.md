# GradlePaperPlugin

GradlePaperPlugin is a Minecraft plugin designed for Paper servers, specifically targeting version 1.21.11. It provides a basic structure for developing plugins using Gradle, a popular build automation tool. The plugin includes a simple command that greets players, demonstrating the plugin's functionality.

## Install

1. Ensure you have Java Development Kit (JDK) 21 installed.
2. Install Gradle by following the instructions on the [Gradle official website](https://gradle.org/install/).
3. Clone the repository to your local machine.
4. Navigate to the project directory in your terminal.
5. Run `gradle build` to build the plugin.
6. The compiled plugin JAR file will be located in the `build/libs` directory.

## Use

1. Place the compiled JAR file in the `plugins` directory of your Paper server.
2. Start or restart your Paper server.
3. Use the `/ciao` command in-game to greet yourself.
